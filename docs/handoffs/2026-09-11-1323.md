## Was wir gemacht haben

HP Sure Click stufte `Find-WmicUsage.ps1` auf dem Zielsystem als
**`Win32.Malware-Behavioural`** ein. Das Werkzeug wurde daraufhin in zwei Schritten von den
Konstrukten befreit, die eine Schadsoftware-Erkennung auf sich ziehen, ohne dass eine
Funktion verlorenging.

## Erledigt

- [x] **1.2.0 — Testdaten-Generator ausgelagert** nach `New-WmicSampleData.ps1`.
      `-CreateSampleData` und `-Force` entfallen im Scanner, der wieder nur einen
      Parametersatz hat. Kein Code liegt doppelt; das Verdächtige steckt in einer Datei,
      die nie auf ein Zielsystem kommt.
- [x] **1.3.0 — Report wird nicht mehr geöffnet.** `Start-Process` vollständig entfernt,
      Funktion `Open-Report` gelöscht, Schalter `-NoOpen` entfallen. Der Pfad steht am Ende
      allein in einer eigenen Zeile auf der Konsole.
- [x] README und CHANGELOG nachgezogen, inklusive der Begründung, warum die Trennung
      besteht — damit sie niemand aus Bequemlichkeit rückgängig macht.
- [x] Insight zum Fund geschrieben.

**Entscheidender Umstand:** Die Meldung kam beim **Entsperren der heruntergeladenen Datei**,
nicht beim Ausführen. Das Skript hat auf dem Zielsystem nie gelaufen. Die Engine hatte
ausschließlich den Dateiinhalt — `-Behavioural` benennt das Modell, nicht eine Beobachtung.
Inhalt zählt also, und das eingebettete JavaScript ist der letzte verbliebene Kandidat,
falls die neue Fassung erneut anschlägt.

## Entscheidungen dieser Sitzung

- **Trennen statt kopieren.** Eine zweite, schlanke Kopie des Scanners hätte rund 800 Zeilen
  dupliziert und wäre auseinandergelaufen. Stattdessen ist der Scanner generatorfrei und der
  Generator eine eigene Datei.
- **`Start-Process` ganz entfernt, nicht nur der Automatismus.** Ein opt-in `-Open` hätte das
  Konstrukt in der Datei gelassen — und genau das Konstrukt ist das Problem.
- **Eine Variable pro Test.** Das JavaScript bleibt vorerst drin, obwohl es ein Kandidat ist.
  Würden beide Änderungen gleichzeitig greifen, wüsste man hinterher nicht, welche gewirkt hat.
- **`-NoScript` nicht auf Vorrat gebaut.** Aus demselben Grund.
